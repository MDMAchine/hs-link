# Changelog

All notable changes to HOT-STEP LINK.

Development through v0.4.0 happened inside the MDMAchine_VST monorepo. The plugin was split into this repository at commit 87f1ddc.

---

## v0.5.14 -- 2026-10-22

- New GUIDANCE (0-20) and STEPS (1-300) controls in the Generate row. Both default to Auto, which sends neither field, so server behaviour is unchanged until one is moved off its far-left Auto position. Set values are clamped client-side before POST /api/v1/daw/generate. Saved state: two new APVTS params (guidance, steps); sessions saved before v0.5.14 load them as Auto. Not listened to, not cleared for deploy.

## v0.5.13 -- 2026-10-22

- Take list: each take shows a fit-to-bars score ("fit 0-100", TakeGrid::fitToBarsScore): how close its length is to a whole number of host bars, times how close its measured tempo is to the host tempo. New VARIATION control (0-100, Setup row): 0 sends the same seed every generate; higher values step the seed by 8 to 1000 per generate and for "+4 more like take N", deterministically from the base seed (SeedSpread::spread). A random seed stays random. Not listened to, not cleared for deploy.

## v0.5.12 -- 2026-10-22

- GUI (Mockup A): the header status pill now shows the job state too (offline, idle, queued, rendering, error) and its colour follows it. The Collection moved out of the Setup plate into a bottom chip bar (count, search, ALL/SA3/YuE2/ACE/starred chips, one chip per saved take). Not listened to, not cleared for deploy.

## Unreleased -- 2026-10-21

- Take store: an adopted dead folder is kept whole when its scan stopped early or did not sweep (W1), or when it holds anything outside the allowed set: an unlisted take, a cut-short .part, an unknown file or subfolder (W2).
- Note (W3): old folders with no lock file now have every unlisted WAV copied to recovered_*. Users of older builds that never wrote saved.log may see duplicate recovered copies.

## v0.5.11 -- 2026-10-20

- Version bump for local deploy build (no code changes). Formats are VST3, CLAP and Standalone. Installer now packs the CLAP into Common Files\CLAP and shows the AGPL LICENSE.

## v0.5.10 -- 2026-10-18

- Understand: when the 200 response has no analysis_id, the job id falls back to id (fixes "no job id in response" on servers that send only id; commit e435624).
- Tests: uid selector covers extractServerId (analysis_id, id fallback).

## v0.5.9 -- 2026-10-18

- Preview job try/catch ends Loading on throw; test g4.

## v0.5.8 -- 2026-10-17
